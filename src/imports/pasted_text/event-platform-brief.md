Create a modern, premium event-ticketing platform for Burundi called **[BRAND NAME]**.

The platform should feel like a combination of a modern African event marketplace, a professional ticketing platform, and an easy-to-use event management system.

## BUSINESS CONCEPT

[BRAND NAME] helps people in Burundi discover events and buy tickets online, while giving event organizers powerful tools to create, promote, sell, and manage their events.

The initial target market is **Bujumbura, Burundi**, with the visual identity and architecture designed to eventually expand across East and Central Africa.

The platform should support:

* Concerts
* Festivals
* Parties
* Nightlife
* Sports events
* Conferences
* University events
* Comedy shows
* Cultural events
* Business/networking events

## BRAND PERSONALITY

The website should feel:

* Young
* Energetic
* Premium
* African but not stereotypical
* Modern
* Social
* Trustworthy
* Fast
* Easy
* Exciting

Avoid making the website look like a generic corporate banking website or an old-fashioned ticketing website.

Use strong typography, large event photography, clean cards, subtle animations, generous spacing, and a polished mobile-first interface.

The visual style should feel suitable for a major concert or festival but still work for conferences and professional events.

## DESIGN SYSTEM

Use a premium modern design system.

Typography:
Use a modern sans-serif such as Inter, Manrope, Geist, or similar.

Use bold typography for event names and major headlines.

Cards:
Rounded corners but not excessively rounded.

Buttons:
Strong, clear CTAs.

Animations:
Use subtle hover, fade and slide transitions.

Avoid excessive animation.

Photography:
Use high-energy African event photography:

* Concert crowds
* DJs
* Basketball
* Festivals
* Young people
* Nightlife
* Cultural events

Avoid generic Western stock photography whenever possible.

## COLOR DIRECTION

Do NOT use a generic red/blue corporate palette.

Create a distinctive African contemporary palette that feels energetic and premium.

Use one strong primary brand color, a dark neutral foundation, warm supporting tones, and plenty of white/neutral space.

The final color palette should be suitable for:

* Website
* Mobile app
* Tickets
* QR scanners
* Staff uniforms
* Social media
* Event branding

## TECHNICAL DIRECTION

Build the interface with reusable components and a scalable architecture.

Recommended stack:

Frontend:
React / Next.js or equivalent

Backend:
Laravel API

Database:
MySQL or PostgreSQL

Authentication:
Customer and organizer authentication with role-based access control.

QR:
Generate unique secure QR codes for every ticket.

The frontend should be prepared for:

* Payment API integration
* SMS integration
* WhatsApp integration
* Email notifications
* QR scanning
* Organizer analytics

For now, use realistic mock data and simulated payment states where backend integrations are not available.

## FINAL DESIGN GOAL

The final product should look like a **serious African technology company**, not a student project.

It should be something a major Burundi concert promoter would feel comfortable using for a 5,000–20,000 person event.

The experience should combine:

**Event discovery + ticketing + promotion + ticket agents + event management + QR check-in + analytics**

into one cohesive platform.
